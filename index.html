Guía básica de Git y Github

Geovanny Vargas Salas

¿Qué es Git?

Git es un sistema de control de versiones distribuido que permite registrar los cambios realizados en los archivos de un proyecto a lo largo del tiempo. Gracias a él es posible volver a versiones anteriores, trabajar en equipo sin sobrescribir el trabajo de otras personas y mantener un historial ordenado de todo el desarrollo.

¿Qué es GitHub y para qué se utiliza?

GitHub es una plataforma en línea que permite alojar repositorios de código y gestionar proyectos de desarrollo de software utilizando Git. Facilita el almacenamiento de proyectos en la nube, el trabajo colaborativo entre desarrolladores y el seguimiento de los cambios realizados en el código. También permite compartir proyectos, revisar contribuciones de otros desarrolladores, reportar errores y gestionar nuevas funcionalidades.

Ventajas de utilizar Git

  • Mantiene un historial completo de los cambios de cada archivo.
  • Facilita el trabajo colaborativo entre varias personas.
  • Permite crear ramas para probar nuevas ideas sin afectar el código principal.
  • Funciona de forma local, por lo que no depende de una conexión a internet.

Comandos básicos de Git

  • git init: crea un repositorio nuevo en la carpeta actual.
  • git status: muestra qué archivos han cambiado y cuáles están listos para guardarse.
  • git add: prepara los cambios de uno o varios archivos para el siguiente commit.
  • git commit -m "mensaje": guarda en el historial los cambios preparados, con un mensaje que los describe.
  • git push: envía los commits locales al repositorio remoto, por ejemplo en GitHub.
